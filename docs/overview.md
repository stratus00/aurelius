# Unumusu Laboratory — overview

- personal lab, single-purpose physical gadgets.
- Unum Usum = one use, done right. aesthetics + simplicity + function.
- goal: pull people back to the physical world, away from do-everything devices.
- Latin/Roman names. housings handmade from repurposed casings.
- salvaged parts (calc button membrane, LCD, ribbon cable, housings) -> parts bin, never trash.
